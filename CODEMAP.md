## Boundaries worth keeping separate

- `site/`: static web UI, **not** kernel runtime or a web compiler.
- `compiler/`: build-time parser and code generator, currently Python-based.
- `examples/`: examples for language syntax, not hardware acceptance evidence.
- `tests/`: source/unit/static regression checks.
- `agent-evals/`: advisory mapping of source paths to existing tests; never a release gate by itself.
- `docs/`: status, evidence standards, architecture, decisions, and agent navigation.

Do not introduce a long-running agent service, database, or synthetic feature count simply because another larger repository has one.

- `boot/user_timeout.{h,c}`, `boot/user_timeout_frame.{h,c}`: opt-in bounded Ring3 executable CPU x2APIC IRQ timeout using the existing `boot/user_preempt_switch.S` 160-byte M4-D frame ABI; native acceptance `scripts/test_m5_user_timeout.py`, host guard `tests/test_user_timeout_frame.py`; see `docs/M5_USER_TIMEOUT.md`.

- `boot/user_syscall_policy.{h,c}`: M5-E3-C pure owned Ring3 INT80 provenance guard (TSS.RSP0, CR3, selectors, six-frame ownership) for per-program abort of malformed saved user RSP/RIP, without dereferencing them; `tests/test_user_syscall_policy.py` host UBSan and `scripts/test_m5_user_syscall_frame.py` native QEMU proof; [contract](docs/M5_USER_SYSCALL_FRAME.md).

- `boot/user_probe.c`, `scripts/test_m5_user_syscall_eof.py`: opt-in M5-E3 valid last-instruction Ring3 `INT 0x80` exit and per-task rejection of nonterminating final syscalls; actual QEMU native checks and legacy fail-stop; [contract](docs/M5_USER_SYSCALL_EOF.md).
- `boot/user_timeout.c`, `boot/user_probe.c`, `boot/user_syscall_policy.c`: opt-in M5-E3-D x2APIC actual CPU IRQ invalid-user-RSP ownership fallback; `scripts/test_m5_user_bad_irq.py` repeats real QEMU CPU delivery and live HTML text HKEX runs; [contract](docs/M5_USER_BAD_IRQ.md).

- M5-F4 bounded HTML user exit status: `compiler/language.py` / `compiler/htmlk.py` final `<halt code>` validation, `boot/user_probe.c` guarded syscall-1 exit status, `boot/serial_console.c` post-reclaim COM1 output, `scripts/test_m5_html_exit_status.py` actual QEMU acceptance; [evidence](docs/M5_HTML_EXIT_STATUS.md).

- M5-F5 full unsigned user reports: `boot/user_probe.c` native 20-digit formatter and opt-in user syscall ID 2 bound, `scripts/build_boot.py` HTML-only mode, `examples/user-programs/html-u64-report.html`, `scripts/test_m5_html_u64_output.py` actual QEMU tests, host `tests/test_html_user_u64_output.py`; [proof](docs/M5_HTML_U64_OUTPUT.md).

- M5-E3-E poisoned user RSP plus actual CPU #UD: `boot/user_fault_policy.{h,c}` pure five-qword CPU exception frame/owner guard, `boot/user_probe.{h,c}` narrow supervisor-side abort, `boot/exception_idt.c` #UD-only fallback, `scripts/test_m5_user_bad_ud_stack.py` actual QEMU positive/legacy negatives, `tests/native/test_user_fault_policy.c` GCC UBSan guard; [proof](docs/M5_USER_BAD_UD.md).
