커널을
직접 부팅해 보자.

준비된 HTML 소스에서 생성한 실제 x86-64 커널 ISO를 브라우저의 가상 PC에서 부팅해. 단순한 웹 OS 화면이 아니라, 네이티브 부팅 메시지를 직접 확인하는 실험이야.

LOCAL EMULATION · NO SERVER EXECUTION

준비됨 · 아직 가상머신을 시작하지 않았어.

01 / DISPLAY가상 PC 화면실제 VGA · 4:3

02 / SERIAL커널 출력COM1 · 0x3F8

부팅을 시작하면 HTML에서 생성한 커널의 시리얼 출력을 이곳에 표시해.

i VGA 예제는 실제 부팅한 커널이 픽셀을 그려. 나머지 예제는 COM1 중심이라 화면이 비어 있을 수 있어. 기록 다시 보기는 실제 CPU 부팅을 늦추는 기능이 아니야. 모바일에서는 메모리 사용량에 주의해.

ABOUT THIS EXPERIMENT

무엇을 검증하는가?

이 페이지는 HTML 형태의 언어로 작성된 커널을 미리 컴파일한 ISO를 내려받아, 브라우저 내부의 x86-64 에뮬레이터로 실행해. VGA 데모는 실제 커널의 프레임버퍼 픽셀을 보여주며, 결과의 정확성은 실제 COM1 시리얼 출력으로 확인해.

정확한 범위 — 현재는 M2의 정수 자료형·함수·조건·반복·배열 등 핵심 부분과 M3의 선택적 물리·가상 메모리 및 CPU 예외 실험이 구현됐어. 범용 메모리 관리, 파일 저장, 키보드 드라이버, 스케줄러, 그래픽 데스크톱은 아직 구현되지 않았어. 브라우저 가상머신 부팅이 물리적 PC 지원을 증명하지는 않아.
