    ABOUT THIS EXPERIMENT

    무엇을 검증하는가?

    이 페이지는 HTML 형태의 언어로 작성된 커널을 미리 컴파일한 ISO를 내려받아, 브라우저 내부의 x86-64 에뮬레이터로 실행해. 부팅 처음부터 실제 BIOS의 VGA 문자 기록과 커널의 COM1을 분리해서 보여주고, 선택한 ISO를 빌드할 때 사용한 HTML 소스를 함께 표시해. ISO 자체는 전부 HTML이 아니고, Limine 부트로더·설정 파일과 HTML에서 컴파일한 네이티브 ELF 커널 등으로 이루어져 있어. COM1에 일치한 일반 <print> 텍스트만 원본 소스에서 강조하며, 임의의 함수나 명령어 실행 위치까지 추적한다고 주장하지 않아.

    정확한 범위 — 현재는 M2의 정수 자료형·함수·조건·반복·배열 등 핵심 부분과 M3의 선택적 물리·가상 메모리 및 CPU 예외 실험이 구현됐어. 범용 메모리 관리, 파일 저장, 키보드 드라이버, 스케줄러, 그래픽 데스크톱은 아직 구현되지 않았어. 브라우저 가상머신 부팅이 물리적 PC 지원을 증명하지는 않아.
