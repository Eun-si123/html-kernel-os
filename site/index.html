01 / THE IDEA

브라우저를 벗어난 HTML.

웹 OS처럼 보이는 인터페이스가 아니야. HTML 태그로 커널 동작을 표현하고 이를 실제 CPU 명령어로 컴파일하는 걸 목표로 해.

01

HTML as source

<kernel>, <onboot>, <print> 등 선언적 태그로 동작을 작성해.

02

Native compilation

초기 컴파일러가 HTML을 freestanding C로 변환하고, GCC가 x86-64 오브젝트를 생성해.

03

Bare-metal ambition

궁극적으로 독립 부팅, 메모리 관리, 인터럽트, 프로세스와 드라이버까지 확장해.

02 / THE PROTOTYPE

태그에서 네이티브 코드로.

현재 구현은 제한적인 구문을 C로 변환하는 첫 단계야. 아래는 읽기 전용 미리보기이며 실제 커널 실행 화면은 아니야.

static inline void outb(unsigned char v) {
  __asm__ volatile ("outb %0, %1"
    : : "a"(v), "Nd"((unsigned short)0xE9));
}
void kernel_main(void) {
  /* <print> emits bytes via debugcon */
  /* compiler-generated byte arrays go here */
  __asm__ volatile ("cli");
  for (;;) __asm__ volatile ("hlt");
}
QEMU debugcon 0xE9 · 부팅 연결은 향후 작업

구현 범위 안내: 아직 부팅 가능한 커널·파일 시스템·태스크 스케줄러는 없어. 이 페이지는 소개 사이트이고, 실제 코드는 GitHub에서 확인할 수 있어.
