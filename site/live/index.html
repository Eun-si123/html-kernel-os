M5 / NATIVE HTML EXPERIMENT

HTML로 작성하고.
실제 CPU에서 실행한다.

HTML 형태의 프로그래밍 언어가 네이티브 커널과 Ring 3 사용자 프로그램으로 컴파일돼. 이 페이지는 실제 x86-64 부팅 ISO를 브라우저 에뮬레이터에 넣고 명령을 가상 COM1로 전송하는 실행실이야.

정확한 의미: 표준 HTML 파일 자체를 CPU가 실행하는 건 아니야. 프로젝트의 HTML형 언어 → C/어셈블리 → ELF/HKEX → 실행 순서야. GitHub Pages는 정적 사이트야. 웹에서는 실제 Python 컴파일러가 HTMLK를 C로 변환할 수 있지만, x86-64 HKEX·ISO 생성은 아직 PC의 네이티브 빌더가 필요해.

실제 실행까지

  1. 이 편집기에서 HTML형 프로그램 작성 후 HTML 파일 저장
  2. GitHub 저장소를 받은 PC에서 아래 진짜 네이티브 ISO 빌드 명령 실행
  3. 생성된 build/my-html-os/html-kernel-live.iso를 아래 내 빌드 ISO로 선택하고, 원본 HTML도 함께 선택
  4. 실제 ISO 부팅 → cat /source.html로 원본 확인 → run /apps/hello.hke로 CPU 실행

    버튼을 누르면 고정 버전 외부 Pyodide 실행 파일을 받아 Web Worker 안에서 저장소의 동일한 Python 컴파일러를 실행해. 소스는 컴파일러에 데이터로만 전달하며 서버로 직접 업로드하지 않아. 하지만 외부 CDN 코드 의존성이 있으므로 민감한 원본에는 사용하지 않는 편이 안전해.
