M5 / NATIVE HTML EXPERIMENT

HTML로 작성하고.
실제 CPU에서 실행한다.

HTML 형태의 프로그래밍 언어가 네이티브 커널과 Ring 3 사용자 프로그램으로 컴파일돼. 이 페이지는 실제 x86-64 부팅 ISO를 브라우저 에뮬레이터에 넣고 명령을 가상 COM1로 전송하는 실행실이야.

정확한 의미: 표준 HTML 파일 자체를 CPU가 실행하는 건 아니야. 프로젝트의 HTML형 언어 → C/어셈블리 → ELF/HKEX → 실행 순서야. GitHub Pages는 정적 사이트라 원본을 수정해 즉시 재컴파일하는 기능은 아직 없어.

03 / HOW IT WORKS

실행 경로

  1. HTML source<print>와 <halt>로 행동 작성
  2. Compiler빌드 시 HTML → C → 네이티브 ELF → HKEX
  3. BootWASM x86-64 에뮬레이터에서 SeaBIOS → Limine
  4. Ring 3ROMFS 실행 파일을 사용자 전용 페이지로 로드
  5. COM1실제 CPU syscall 출력·종료 코드·메모리 회수

이 브라우저용 빌드는 x2APIC 타임아웃 없이 작동해. 오류가 있는 프로그램이 멈출 가능성이 있으며, 범용 앱·하드웨어 보안이나 실기기 호환성을 보장하지 않아. 기술 검증 ↗ · v86 라이선스 ↗
